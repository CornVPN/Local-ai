# 🧠 Введение

В этом руководстве показано, как запустить локальные ИИ-модели прямо на Android-устройстве.

Используем:

- **Termux** — Linux-терминал для Android
- **Ollama** — инструмент для запуска локальных LLM-моделей

После установки вы сможете запускать:

- Gemma
- Llama
- Phi
- Qwen
- Mistral
- DeepSeek

и многие другие модели.

---

> ⚠️ Все действия вы выполняете на свой страх и риск.

### 📱 Желательные характеристики устройства

| Параметр | Рекомендуется |
|---|---|
| Android | 10+ |
| ОЗУ | 4 ГБ и больше |
| Свободная память | от 5 ГБ |
| Процессор | ARM64 |

Чем мощнее устройство — тем лучше будет работать модель.

# 📦 Что понадобится

## ✅ Termux

Рекомендуется устанавливать через GitHub или F-Droid.

### Официальные источники

- GitHub: https://github.com/termux/termux-app
- F-Droid: https://f-droid.org/packages/com.termux/
- Google Play: https://play.google.com/store/apps/details?id=com.termux

# ⚙️ Установка Termux

После установки откройте Termux и дождитесь первой инициализации.

## 🔄 Обновление пакетов

```bash
pkg update && pkg upgrade -y
```

или:

```bash
apt update && apt upgrade -y
```

---

# 🤖 Установка Ollama

## 1️⃣ Подключение TUR-репозитория

```bash
pkg install tur-repo -y
```

## 2️⃣ Установка зависимостей

```bash
pkg install git cmake golang -y
```

## 3️⃣ Установка Ollama

```bash
pkg install ollama -y
```

---

# ▶️ Запуск Ollama

После установки запустите сервер:

```bash
ollama serve
```

После запуска желательно открыть новую сессию Termux.

### 📌 Как открыть новую сессию

```text
Меню → New Session
```

---

# 📥 Загрузка и запуск модели

Для примера установим модель:

```bash
gemma3:1b
```

### Установка и запуск

```bash
ollama run gemma3:1b
```

Размер модели — примерно **900 МБ**.

После успешной загрузки откроется чат с моделью.

# 🛠 Полезные команды

## 📋 Показать модели

```bash
ollama list
```

---

## ❌ Удалить модель

```bash
ollama rm НАЗВАНИЕ_МОДЕЛИ
```

Пример:

```bash
ollama rm gemma3:1b
```

---

## 🛑 Остановить сервер

```bash
CTRL + C
```

---

## 📌 Проверить версию

```bash
ollama --version
```

---

# ⚠️ Возможные ошибки

## ❌ `pkg: command not found`

Попробуйте:

```bash
apt update
```

или переустановите Termux.

---

## ❌ `Cannot connect to Ollama`

Проверьте, запущен ли сервер:

```bash
ollama serve
```

---

## ❌ Недостаточно памяти

Попробуйте лёгкие модели:

- gemma3:1b
- tinyllama
- phi3-mini
